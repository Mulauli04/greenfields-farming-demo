# GreenFields demo test checklist

Test in desktop and mobile browsers. Mark each item after manual verification.

- [ ] Home, Products, Product Details, About, Our Farm and Contact pages load.
- [ ] Presentation links open the intended pages.
- [ ] Navigation is usable on narrow mobile screens.
- [ ] Product search and category filters work.
- [ ] Product detail view matches the selected item.
- [ ] Quote form rejects missing required fields.
- [ ] Fictional enquiry is stored and visible in admin dashboard in the same browser.
- [ ] Enquiry status changes persist after refresh.
- [ ] Add/edit/hide a sample product and check the public catalogue.
- [ ] Create a demo order and change its status.
- [ ] Clear/reset demo data after presenting.
- [ ] No real personal data is entered.
- [ ] External photos and Bootstrap load with internet connection.

Automated static checks confirm file presence and local link targets, not full browser functionality.
