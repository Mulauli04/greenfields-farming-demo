# GreenFields Homepage Redesign — Page 1

This package contains the complete existing 10-page website plus an upgraded `index.html` homepage.

## What's new
- Full-screen 3-photo slideshow with accessible controls and reduced-motion support.
- Redesigned introduction with overlapping real farm photos.
- Premium photo-led crop cards.
- Four-stage farm journey.
- Harvesting feature and prominent enquiry section.
- Mobile-responsive layout.
- Homepage-specific files: `assets/css/home-premium.css` and `assets/js/home-premium.js`.

## Install on GitHub Pages
Upload the contents of this folder to the root of your existing `greenfields-farming-demo` repository, preserving the `assets` folder. Existing pages are included and retained. Do not upload the enclosing `GreenFields_Home_Redesign` folder as an extra nested directory.

## Test
Open `index.html`, use the slideshow controls, select crop cards, check all navigation links, and test on mobile.

## Note
No business phone number, prices, or email address were invented. Enquiry buttons link to the existing `enquiries.html` page. Admin/backend features remain demonstrations until connected securely.
